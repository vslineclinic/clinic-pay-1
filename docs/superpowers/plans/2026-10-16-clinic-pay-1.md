# Clinic Pay 1 Implementation Plan
> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 기존 운영앱을 유지하고 새 저장소·주소에 확장된 수납·정산 개발본을 제공한다.
**Architecture:** 기존 Python 엔진/인증을 재사용한다. 별도 PostgreSQL 원장과 행 단위 자동저장 컴포넌트, 마감 이력을 연결한다.
**Tech Stack:** Python/Streamlit/pandas, psycopg, SQLite(local only), vanilla JS component.
**Spec:** docs/superpowers/specs/2026-10-16-clinic-pay-1.md

## Global Constraints
- 기존 vslineclinic/clinic-pay에는 push/배포 금지.
- 새 app은 admin/all만. 직원 공개는 별도 이후 요청.
- 실데이터/비밀번호/API키/DB URI 커밋 금지.
- 모든 금액 integer KRW, canonical 7 branches.
- 원격 DB 미연결이면 영구 저장/운영 준비 완료 주장 금지.

## Review Focus
- 저장 응답 유실 후 동일 요청 재전송은 거래 1건.
- stale editor는 새 거래 개정을 덮지 않는다.
- close와 save 경합은 snapshot과 day 상태 일치.
- 로그아웃/계정 취소/날짜 전환은 다른 지점 자료를 노출하지 않는다.
- 빈 자료·잘못된 숫자·부분 날짜 누락은 정상 0으로 집계하지 않는다.
